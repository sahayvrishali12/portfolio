HR Governance Audit

Overview & Problem

A role-based web application built to address the complexity of auditing an organization's HR policy governance. The platform centralizes a 25-document compliance checklist, replacing manual tracking with an automated, role-aware system.

My Contribution

Built during my internship as an AI Analyst at Aim Elevate Ventures, under the guidance of Founder & CEO Ira Agarwal. I designed and implemented the end-to-end platform, including the RBAC system, scoring engine, and AI integration.

Technical Approach & Features

The platform features a granular Role-Based Access Control (RBAC) system managing Admin, HR Manager, HR Employee, and IT roles with server-enforced permissions. The core logic calculates a dual scoring system: an Audit Score (documents available vs. total) and a weighted Compliance Score mapping to maturity bands.

Additionally, I embedded an AI Q&A assistant into the audit pages to help administrators interactively query specific audits or general HR governance policies, alongside an AI-generated narrative report summarizing the organization's compliance posture.

Tech Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · JSON Storage · NVIDIA LLM API

Cardiovascular Risk Prediction

Overview & Problem

Cardiovascular disease is a leading cause of mortality worldwide. This project addresses the need for early identification by building a data-driven risk assessment system. It evaluates structured clinical features (e.g., age, blood pressure, cholesterol, heart rate) to predict disease risk, reducing reliance solely on inconsistent specialist judgments.

Technical Approach

The project utilizes the Cleveland Heart Disease dataset (303 records, 13 features). I implemented a robust preprocessing pipeline including median imputation for missing values, feature scaling using StandardScaler, and target binarization.

I developed two types of models: Regression models (Linear, Ridge, Lasso) to generate a continuous risk score, and Classification models (Logistic Regression, Decision Tree, Random Forest) for binary diagnosis.

Outcome

Random Forest emerged as the best-performing model, achieving 86% accuracy and an F1 score of 0.84 on the clinical data. The pipeline successfully generated actionable visualizations including risk score thresholds, disease probability charts, and feature importance mappings.

Tech Stack

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn

Crop Growth Advisory System

Overview & Problem

A machine learning study designed to provide crop growth simulation and advisory support to help farmers make informed, data-driven decisions based on environmental parameters.

Technical Approach & Outcome

Using a public crop prediction dataset from Kaggle, I applied and evaluated machine learning models to accurately predict crop growth patterns. I tested XGBoost initially, but Random Forest produced more dependable simulation results.

Air Quality Forecasting

Overview & Problem

Public air quality dashboards are typically reactive, only reporting past or current conditions. This project bridges the gap by providing a real-time, highly localized forecasting engine, empowering communities to anticipate hazardous pollution spikes 48 hours in advance rather than relying on generalized, computationally expensive government models.

Technical Approach & Architecture

The backend is a FastAPI application that actively scrapes live sensor data from the OpenAQ network and meteorological data from Open-Meteo. I implemented a modular forecast registry featuring univariate models (ARIMA, Facebook Prophet) and weather-aware models (SARIMAX, XGBoost).

Forecasts are strictly evaluated against held-out historical actuals (calculating RMSE, MAE, MAPE). A lightweight file-based caching system is used instead of a database, ensuring instantaneous model switching.

I also integrated an NVIDIA-NIM-powered AI layer that deterministically explains the analytical results via natural language, without fabricating data.

Tech Stack

React · TypeScript · FastAPI · Python · ARIMA / SARIMAX · Facebook Prophet · XGBoost · NVIDIA NIM
